1. Image

Aucune image chargée.

2. Calibration des axes

Placez quatre repères : deux sur l’axe X (seule leur valeur X compte), deux sur l’axe Y. Les axes peuvent être inclinés ou cisaillés.

RepèreValeurPosition px

Les positions se corrigent au clavier autant qu’à la souris : saisir « 84, 315 » place le repère au pixel exact, ce qu’un clic ne garantit jamais.

3. Zone d’analyse

Restreindre la détection au cadre du tracé évite de capter les axes et les étiquettes. Excluez la légende : elle contient des segments de la couleur exacte des courbes, qu’aucune tolérance ne peut distinguer.

Zone : image entière.

    4. Séries
      Marqueur de la série active

      Un disque de deux pixels posé sur un trait noir de deux pixels est invisible : c’est exactement là qu’on pointe. Les formes creuses — anneau, croix, plus — laissent voir la courbe sous le marqueur.

      Pointer ajoute un point à la série active. Gommer retire le point le plus proche d’un clic ; en glissant, il retire d’un coup tous les points de la série active contenus dans le rectangle.

      5. Détection automatique

      La teinte distingue les courbes entre elles ; la clarté absorbe l’anticrénelage des bords du trait. Pour une courbe noire ou grise, seule la clarté discrimine : resserrez-la.

      Sur une planche en noir et blanc, deux courbes n’ont souvent que leur tracé pour les distinguer. Aucune tolérance de couleur ne peut les séparer ; le tri sur le type de trait, si.
